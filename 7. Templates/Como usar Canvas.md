# Como usar este Canvas

Um **Canvas** serve para desenhar relações: mapa de regiões, teia de facções, fluxo de pistas ou linha do tempo visual.

## Ideias de canvas para um vault de RPG

- **Mapa do mundo** — nós com as regiões e setas indicando rotas.
- **Teia de facções** — organizações ligadas por aliança/rivalidade.
- **Fluxo de pistas** — de onde cada pista leva (ótimo para investigação).
- **Linha do tempo** — sessões e eventos em sequência.

Para criar: `Ctrl/Cmd + P` → **Canvas: Criar novo canvas**. Salve na pasta correspondente (ex.: `2. Lugares/Mapa do mundo.canvas`).

Apague esta nota quando não precisar mais dela.
