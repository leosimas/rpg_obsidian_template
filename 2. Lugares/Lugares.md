# Lugares

Cidades, vilas, masmorras, regiões e pontos de interesse. Uma nota por lugar, criada a partir de [[Template - Lugar]].

## Convenção de nome

- Nome próprio do lugar como título: `Rotimburgo`, `Taverna Gata no Cio`.
- Se houver dois lugares com o mesmo nome, qualifique entre parênteses: `Portão Norte (Ruínas)`.

## Organização sugerida (quando o cenário crescer)

```
2. Lugares/
    Cidades e vilas.md      ← hub por escala, opcional
    Regiões.md
    Masmorras.md
```
