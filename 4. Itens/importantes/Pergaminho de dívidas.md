# Pergaminho de dívidas

**Tipo:** importante (pista)
**Portador:** [[Damião Talv]]
**Aventura:** [[Capítulo 01 - Ladrões na Estrada]]

## Descrição

Pergaminho dobrado em quatro, gasto nas dobras, com uma tabela escrita à mão em letra pequena. É a conta da família Talv com os agiotas.

| Data | Valor cobrado | Observação |
|------|---------------|------------|
| 14/03 | 40 moedas | dívida inicial |
| 21/03 | 38 moedas | |
| 28/03 | 36 moedas | |
| 04/04 | 33 moedas | "atrasou — dobra" |
| 11/04 | 31 moedas | |
| 18/04 | 28 moedas | |
| 25/04 | ? | próxima entrega |

**O que a tabela revela:** os valores caem devagar — a dívida é longa e foi feita para nunca terminar. A anotação "dobra" mostra o que acontece com quem atrasa.

## Efeitos em jogo

- Prova de que os assaltos são cobrança, não bandidagem comum.
- Com a tabela e o [[Caderno-razão do Brás]], os PJs podem provar o esquema para a vila.

## Riscos e limitações

- É só a dívida dos Talv: sozinho não prova nada sobre os outros moradores.
- Se os PJs entregarem o pergaminho a Brás, ele "perde" o documento na hora.
