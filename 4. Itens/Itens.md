# Itens

Equipamentos, tesouros, artefatos e bugigangas.

## Onde colocar cada nota

| Pasta | O que vai ali |
|-------|----------------|
| `4. Itens/importantes` | itens de trama, artefatos centrais, recompensas decisivas |
| `4. Itens/tabelas` | itens opcionais gerados por tabela/rolagem |
| `4. Itens` (raiz) | equipamento comum, tesouro secundário |

## Convenção de nome

- Nome do item como título: `Colar de prata`.
- Itens com nome genérico recebem um qualificador: `Espada (lama preta)`.
